# カテゴリ操作

管理シート上部の B1「入力内容を処理する」で、受付時点の入力だけを実行する。受付後はシートを閉じてよい。受付シートがある環境では定期取込や旧 `categories` スコープは未送信の入力を処理しない。

- E列「今後の自動分類」: `登録する` は次回処理で保存、`登録しない` は追加登録を見送る意思を保持、`未選択` は未決定。以前のチェック済みも登録要求として読み取る。既存ルールの無効化はこの選択に含まない。
- F列「過去分にも反映（全月）」: B1で実行すると、同じデータ元・口座・請求名に完全一致する全月の「その他／未分類」に選択カテゴリを反映する。分類済みの明細は変更しない。固定対象を内部で保存・再照合してから反映し、未来の自動分類ルールはE列で別に選択する。
- 月を限定したい場合は第2段階の期間と「プレビューする」を使う。
- 第3段階: 固定された件数と対象を確認して「この件数に反映」にチェックする。次回処理はこの確認済みの未分類明細だけを変更する。

全月反映が完了し、同条件の未分類が残っていない場合は別月分の候補も一覧から除く。処理記録と明細は残す。未反映・保留は一覧に残り、新しい未分類が入れば再表示する。今後の自動分類だけを処理した行は従来どおり末尾へ並べる。

旧見出し「過去分の候補に追加」で受付済みの入力は、全月反映へ読み替えない。新しい見出しが表示された状態でB1から送信した入力だけが全月反映になる。

本番設定は `CATEGORY_RULE_UI_ENABLED` / `CATEGORY_RULE_SAVE_ENABLED` / `CATEGORY_BACKFILL_PREVIEW_ENABLED` / `CATEGORY_BACKFILL_APPLY_ENABLED`。各機能は明示的に有効な場合だけ実行する。`preview` 実行は表示更新も含めて書き込みを行わず、ログは件数のみ。カテゴリ変更後は投影と日常画面を更新する。
