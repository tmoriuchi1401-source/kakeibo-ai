# 領収書確認シートの使い方

通常は黄色い M 列「判断」のプルダウンを選ぶだけです。選択内容は次の取込処理で反映され、完了行は非表示になります。反映できない場合は P 列「反映結果」を確認してください。見出しのメモにも操作説明があります。

## 一般レシート

1. D 列の原本リンクを開き、F 列「既存値」と G 列「候補（未確定）」を比較します。
2. M 列で判断を選びます。
   - **既存値を維持**：現在の記帳が正しい。記帳内容を変更せず確認を終えます。
   - **候補明細で確定**：候補を採用して記帳内容を更新します。
   - **保留**：判断できない。反映を保留します。

H～L 列の医療用入力は不要です。確認が必要な医療の行も入力途中の値もないとき、この欄は自動で非表示になります。

## 医療の領収書

G 列の候補が原本と一致していれば「候補で医療費を確定」を選択できます。不足・修正がある場合だけ H～L 列を入力します。入力値を優先し、空欄だけ候補から補います。

- H：支払日。日付セルのダブルクリックでカレンダーを開きます。
- I：施設名。候補・過去の医療支出から選択できます。新しい施設は直接入力できます。
- J：本人が実際に支払った金額。円単位の数値を入力します。
- K：医療費カテゴリを選択します。
- L：支払方法を選択します。任意入力で、新しい方法は直接入力できます。

候補を使用せず H～K 列を入力した場合は「医療費を確定」を選択します。

## 重複の確認と種類の保留

同日付近・同額の支出候補がある場合、N 列に支出 ID のプルダウンが表示されます。セルのメモで日付・店舗・金額を確認し、「既存支出と重複（紐付け）」と統合先を選択してください。同じ金額でも別の支払いなら「重複候補と別の支出として確定」を選択します。候補は取込処理のたびに更新され、反映時にも再検証されます。既存のレシート明細がある行では重複統合は選べません。

種類を判定できなかった受付保留の行では、O 列「本人メモ」から「一般の買物／医療／対象外／再撮影が必要」を選べます。補足の自由入力もできます。種類メモは計上の確定操作ではありません。

列の並べ替え・見出し名の変更・確認 ID の編集は行わず、入力欄を使ってください。
